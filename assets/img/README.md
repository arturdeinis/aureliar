# Photography slots

The design is image-led, so these matter as much as the film. All of them are
commented-out `<img>` tags sitting inside a `.frame` in `index.html`.

| File | Where | Crop |
|---|---|---|
| `club-table.jpg` | The Club card I | 3:4 |
| `club-court.jpg` | The Club card II | 3:4 |
| `club-season.jpg` | The Club card III | 3:4 |
| `club-circle.jpg` | The Club card IV | 3:4 |
| `ambassador.jpg` | Ambassadors section | 4:5 |
| Moments rail | Five frames in the Moments strip | 4:5 each |
| `og.jpg` | Social share card, 1200 × 630 | needed before the link is shared |

Treat them as one set: same grade, same warmth, faces and rooms rather than
objects. Dark, low-key frames sit best against the ink bands.
